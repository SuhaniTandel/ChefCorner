## 🔧 If Something Breaks

1. **Check browser error**: Press F12, click Console
2. **Read error message** - It tells you what's wrong
3. **Clear cache**: Ctrl+Shift+Delete
4. **Restart npm**: Stop terminal (Ctrl+C), run `npm start` again
5. **Reinstall**: `npm install`
