## 🎨 Customization (Easy)

### Change Website Title
Edit `public/index.html`:
```html
<title>Your Restaurant Name</title>
```

### Change Colors
Edit `public/assets/style.css` and replace:
```css
#e74c3c  /* Red - primary color */
```

### Change Logo
Replace `/public/assets/img/logo-dark.png` with your logo

### Update Recipe Data
Edit each page's recipe arrays:
```javascript
const recipes = [
  { id: 1, title: "Your Recipe", category: "Category", image: "image.jpg" },
  // Add more
];
```


### Clear all & reinstall
```bash

```

### Check for errors
- Open browser's Developer Tools (F12)
- Go to "Console" tab
- Look for red error messages
- That's what's wrong
